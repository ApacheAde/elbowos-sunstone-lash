# Sunstone Lash

Full-colour Python 3 neon grappling-swing arcade for [ElbowOS](https://x.com/ElbowOS).

Swing a rose-gold beetle through a dusk-violet shaft.
Lash onto drifting amber sunstones. Avoid spinning magenta thorns.
Chain hooks to climb.

Space / W / Up fires the lash. R reset. Esc quit.

## Play

```
pip install -r requirements.txt
python3 sunstone_lash.py --play
```

(or just `python3 sunstone_lash.py`)

## Record a 9:16 reel

```
python3 sunstone_lash.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
